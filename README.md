Features Included:
1.	Authentication & Multi-Role Access: Default Root Admin credentials (admin / admin123) provided on the login page with custom permissions matrix (Yard Admin vs Yard User).
2.	Real-time Online Storage Integration: Uses Firebase Firestore (/artifacts/{appId}/public/data/cyms_*) so all users see real-time updates. Also supports fallback memory mode with a dynamic setup modal.
3.	Sidebar Navigation & Topbar Features: Includes Dashboard, Gate In, Gate Out, Container Inventory, Reports, Settings, Admin Panel, and Log Out. Topbar features Dark/Light mode toggle and real-time Notification Bell for Gate In, Gate Out, and Container Aging (≥ 3 Days).
4.	Gate In & Gate Out Modules: Fully validated forms with dynamic dropdown items from Settings, auto-slot calculation, and Release modals.
5.	Container Inventory & Aging: Calculates aging in days, real-time filters (Search, Type of Move, Date), Status correction (Released ↔ Stored), and CSV export.
6.	Reports Module: Filtering by date range with one-click export to PDF (via jsPDF) and CSV.
7.	Settings Module: Management for Shipping Lines, ISO Sizes/Types, and Yard Slots.
8.	Admin Panel: Company Profile branding (Name, Tagline, Logo URL), User Management (Add/Edit/Delete users & passwords), and Granular Access Matrix.
